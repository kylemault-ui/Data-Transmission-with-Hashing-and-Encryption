# Data-Transmission-with-Hashing-and-Encryption
How to run first download the file, then put it into something like VS Code which I use then you need to install cryptography by typing pip install cryptography and then you can click the run button in the corner, and it should work. What this code does is it lets you type in a message and then it creates a SHA-256 Hash from whatever you put in. After that I it uses AES to encrypt the message and then decrypts it to so you can see the original message again. The program checks the hash again and if they are the same then the message was not changed. It also uses RSA to make a Digital Signature. It makes a private key and a public key. The private key makes the signature, and the public key checks it to make sure it is valid. This shows the CIA triad. first Confidentiality is used by encrypting the message so it cannot just be read. Then Integrity is used by the SHA-256 Hash and Digital Signature to check if the message was changed. Last Availability is shown because the program can be run when it is needed and is esse to run. Randomness is important because encryption keys need to be hard to guess. This program uses random values when making the AES key. RSA also uses randomness when making the private key.
